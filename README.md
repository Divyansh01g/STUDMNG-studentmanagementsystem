# Student Result Management System

A simple Python based application for managing student marks and calculating their academic results.

## Overview

The Student Result Management System allows users to enter student marks, calculate the total and percentage, assign a grade, and search for student records.

The project is developed using basic Python concepts covered in the VITyarthi Python Essentials course.

## Features

- Add student records
- Enter marks for three subjects
- Calculate total marks
- Calculate percentage
- Assign grades
- Search for a student
- View all student records
- Save student records using file handling

## Technologies Used

- Python 3
- Lists
- Dictionaries
- Tuples
- Functions
- Loops
- Conditional statements
- File handling

## Project Structure

- README.md

## How to Run

1. Install Python 3.
2. Open the project folder.
3. Open the terminal in the project folder.
4. Run: `python main.py`
5. Select an option from the menu.

## How It Works

The user enters a student's name and marks for three subjects. The program calculates the total and percentage and assigns a grade based on the percentage.

Student records are stored in `students.txt` so they can be accessed when the program is run again.
