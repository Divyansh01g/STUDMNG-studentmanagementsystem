# Student Result Management System

## Problem Statement

Managing student marks manually can make it difficult to calculate results and find student records quickly. This project provides a simple Python-based system for entering, calculating, storing, and viewing student results.

## Scope

The system allows users to enter marks for three subjects, calculate the total and percentage, assign a grade, search for a student, and view all available student records. The records are stored in a text file.

## Target Users

- Students
- Teachers
- Academic staff

## High-Level Features

- Add student details
- Enter subject marks
- Calculate total marks
- Calculate percentage
- Assign grades
- Search for student records
- View all student records
- Store records using file handling
